# Gemini CLI adapter

Gemini CLI stops context discovery at the Git root, so this file is the in-repository pointer.

Read `AGENTS.md` in this repository before changing code. Those framework rules remain in force.

When `../development-control/RESUME.md` exists, read it before choosing work. That directory is private workspace control and is not part of this public repository. When it is missing, follow `docs/ROADMAP.md` and do not create it inside this repository.

Do not start a milestone whose control-plane status is PROPOSED. Do not mark human approvals complete. Do not approve visual baselines unless the user explicitly asks.
